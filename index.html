ഫോണിൽ ഇൻസ്റ്റാൾ ചെയ്യുന്ന വിധം (Installation Guide)

  1. മുകളിലുള്ള Download Android APK ബട്ടണിൽ ക്ലിക്ക് ചെയ്ത് KKHM-Off-Course-debug.apk ഡൗൺലോഡ് ചെയ്യുക (GitHub Actions-ൽ ആദ്യ ബിൽഡ് പൂർത്തിയായ ശേഷം ഈ ലിങ്ക് സജീവമാകും).
  2. ഡൗൺലോഡ് ആയ APK ഫയൽ തുറന്ന് Android ഫോണിൽ Install നൽകുക (ആവശ്യമെങ്കിൽ Allow from this source അനുവദിക്കുക).
  3. ആപ്പ് തുറന്ന് Google അക്കൗണ്ട് വഴി വെരിഫൈ ചെയ്ത ശേഷം, കോളേജ് അഡ്മിൻ നൽകിയ Username & Password ഉപയോഗിച്ച് ലോഗിൻ ചെയ്യുക.
